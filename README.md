# NEX+ Home

Este repositório contém a nova base limpa do projeto **NEX+ Home**.

---

### Diretrizes de Governança e Repositório

- **Projeto Limpo:** Este é o repositório oficial da nova base.
- **Legado:** O projeto Legacy não faz parte deste repositório e serve estritamente como referência histórica externa.
- **Fluxo de Trabalho Git:**
  - Todo o desenvolvimento deve ocorrer exclusivamente em branches de trabalho (`feat/*`, `fix/*` ou `lab/*`).
  - A branch `main` representa unicamente o estado estável, auditado e formalmente aprovado.
  - Nenhum desenvolvimento direto deve ser realizado na `main`.
